# S5. 보완조치(100일) 문서 작성 보조 및 마감 추적

> English: [remediation.md](remediation.md)

`system-grounding.md`를 먼저 적용한 뒤 사용합니다.

```
[작업] 결함보고서 항목에 대한 보완조치 내역서/완료확인서 초안과 마감 추적표를 작성하십시오.

입력:
- 결함보고서 항목: {{결함 내용 + 해당 인증기준 번호}}
- 결함 통보일: {{YYYY-MM-DD}}

[절차]
1. 각 결함의 인증기준 번호로 docs/ 해당 항목 .md 를 읽고, "세부 설명 + 증적자료"를 조치 방향 근거로 인용한다.
2. 결함별 보완조치 방향(조치 전 -> 조치 후)과 제출 증적 후보를 제시한다.
3. 마감 타임라인을 계산한다: 통보일 + 40일(1차) / 연장 포함 총 100일(최종). 기한 산정은 심사팀 통보 원문과 대조하도록 표시한다.
4. "조치 완료" 표기는 담당자 서명 전까지 "제안" 상태로 둔다(실제 완료 판정은 사람).

[출력] templates/remediation.md 양식(결함번호/조치 전후/증적/마감일)으로
extended/outputs/remediation/<심사회차>/remediation-plan-<날짜>.md 로 저장한다.
```

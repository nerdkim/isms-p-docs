# S6. 심사 모의 질의응답 / 인터뷰 대비

> English: [mock-audit.md](mock-audit.md)

`system-grounding.ko.md`를 먼저 적용한 뒤 사용합니다.

```
[작업] 지정 분야/항목에 대한 심사 모의 질의응답을 생성하십시오.

입력:
- 적용 세트: {{별표7 / 별표7의2 / 별표7의3}}
- 인증 구분: {{ISMS / ISMS-P}}
- 대상 분야 또는 항목(분야명으로): {{예: 접근통제}}

[절차]
1. extended/manifest.json으로 대상 항목을 확정하되 `appliesTo`에 인증 구분이 들어 있는 항목만 남기고(ISMS에는 모든 세트의 3.x 항목이 빠지고, 별표 7의2에서는 고시 제23조제3항제2호에 따라 1.1.2 항목도 빠집니다), 각 항목의 .md를 읽습니다.
2. "주요 확인사항"을 심사원 예상 질문으로 변환합니다.
3. "세부 설명 + 증적자료"를 근거로 모범 답변 골격과 제시할 증적 목록을 만듭니다(각 답변에 근거 인용).
4. 흔히 지적되는 결함 분야(인증 및 권한관리, 접근통제, 암호화 적용, 시스템 및 서비스 운영관리)를 manifest의 `subgroup` 이름으로 찾아 우선 다룹니다. 번호는 별표 7과 7의3에서 2.5/2.6/2.7/2.9, 별표 7의2에서 2.4/2.5/2.6/2.8입니다.
5. 답변에 포함된 사실관계는 자사 실태에 맞게 교정해야 한다는 점을 [자사 확인]으로 표시합니다.

[출력] templates/mock-audit-qna.md 양식(예상질문/답변골격/필요증적/근거 인용)으로
extended/outputs/mock-audit/qna-<분야>-<날짜>.md로 저장합니다.
```

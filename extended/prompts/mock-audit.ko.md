# S6. 심사 모의 질의응답 / 인터뷰 대비

> English: [mock-audit.md](mock-audit.md)

`system-grounding.md`를 먼저 적용한 뒤 사용합니다.

```
[작업] 지정 분야/항목에 대한 심사 모의 질의응답을 생성하십시오.

입력:
- 적용 세트: {{별표7 / 별표7의2 / 별표7의3}}
- 대상 분야 또는 항목: {{예: 2.6 접근통제}}

[절차]
1. extended/manifest.json 으로 대상 항목을 확정하고 각 항목 .md 를 읽는다.
2. "주요 확인사항"을 심사원 예상 질문으로 변환한다.
3. "세부 설명 + 증적자료"를 근거로 모범 답변 골격과 제시할 증적 목록을 만든다(각 답변에 근거 인용).
4. 빈출 결함영역(2.5/2.6/2.7/2.9)을 우선한다.
5. 답변에 포함된 사실관계는 자사 실태로 교정해야 함을 [자사 확인] 으로 표시한다.

[출력] templates/mock-audit-qna.md 양식(예상질문/답변골격/필요증적/근거 인용)으로
extended/outputs/mock-audit/qna-<분야>-<날짜>.md 로 저장한다.
```

# 자료집 사용 규약(USAGE)

> English: [USAGE.md](USAGE.md)

이 문서는 소비자 쪽 AI가 지킬 운영 규약입니다. `docs/` 인증기준 자료집을 써서 ISMS-P 업무를 하는
AI가 대상입니다. 이 저장소 자체를 관리하는 규칙은 루트 `CLAUDE.md`와 `AGENTS.md`에 있습니다.

> 자료집을 다른 저장소/환경에서 소비한다면, 이 문서의 내용을 그 환경의 `AGENTS.md`(Codex) 또는
  `CLAUDE.md`(Claude Code)에 반영해 사용하십시오.

## 권위 출처와 쓰기 범위

- `docs/`는 **읽기 전용** 권위 자료집입니다. 어떤 경우에도 `docs/` 하위를 생성/수정/삭제하지
  않습니다.
- 모든 산출물은 `extended/outputs/` 아래에만 작성합니다.
- 권위 출처는 `docs/` 228개 `.md`, `extended/manifest.json`, `extended/index/*`, 그리고
  `references/`의 원문뿐입니다. 모델 일반지식으로 인증기준/법규/수치를 단정하지 않습니다.

## 작업 순서(manifest 우선)

1. `extended/manifest.json`을 먼저 읽어 질문/작업에 관련된 항목(`no`, `path`)으로 범위를 좁힙니다.
   `docs/` 전체를 무작위 grep 하지 않습니다.
2. 좁힌 항목의 `.md`만 컨텍스트로 읽습니다. 각 파일은 6개 섹션(인증기준 / 주요 확인사항 / 세부 설명
   / 관련 법규 / 증적자료 / 결함사례)으로 구성됩니다.
3. 셀프 진단/mapping이 필요하면 `extended/index/defect-rulebook.json`(결함 룰),
   `evidence-dictionary.json`(증적 사전)을 사용합니다.

## 산출 규칙

- **인용 강제**: 모든 주장/판정 끝에 `[근거: <docs 경로> > <섹션명>]`을 붙입니다. 인용할 수 없는
  내용은 출력하지 않거나 "근거 없음(자료집 미수록)"으로 표기합니다.
- **플레이스홀더**: 자료집에 없는 수치/사실은 `[확인필요]`로 비웁니다.
- **상태 표기**: 산출물 머리에 `상태: AI 생성 초안 / 검토 전`, 생성 일시, 모델 버전, 근거 항목
  목록을 적습니다.
- **사람 게이트**: 법규 해석, 인증 적부 판단, 정책 확정, 충족/미충족 최종 판정, 보완조치 완료 판정은
  사람이 확정합니다. 해당 산출물은 `extended/outputs/review-queue/`에 검수 항목으로도 남깁니다.
- **최신성 경계**: 자료집 기준일(세부점검항목 2023.10.31 / 인증기준 안내서 2023.11.23)을 표기하고,
  2026 개편 등 미수록 개정은 단정하지 않고 "자료집 미수록, 외부 확인 필요"로 플래그합니다.
- **DLP**: 실제 개인정보/원본 증적 본문을 외부 모델에 입력하지 않습니다. 증적은 파일명/유형/메타데이터 수준으로만 다룹니다. <!-- conventions-allow: 공식 표준 용어(데이터, 네트워크) 원문 보존 -->

## 스타일

- 사용자 대상 문장은 존댓말을 사용합니다.
- em-dash(U+2014)와 가운뎃점(U+00B7, U+2219, U+318D)을 쓰지 않습니다. 구분/연결은 슬래시(/),
  콜론(:), 쉼표(,), 괄호, '및'으로 합니다. 원문에 가운뎃점이 있어도 산출물에서는 슬래시로 바꿉니다.

## 검증(권장 CI 린트)

- `git diff -- docs/`가 비어있어야 합니다(자료집 불변).
- `extended/outputs/` 산출물에 최소 1개 이상의 `[근거: docs/...]` 인용이 있어야 합니다.
- 산출물에 em-dash(U+2014)와 가운뎃점(U+00B7, U+2219, U+318D)이 없어야 합니다.

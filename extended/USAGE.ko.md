# 자료집 사용 규약(USAGE)

> English: [USAGE.md](USAGE.md)

이 문서는 consumer 쪽 AI가 지킬 운영 규약입니다. `docs/` 인증기준 자료집을 써서 ISMS-P 업무를 하는
AI가 대상입니다. 이 repository 자체를 관리하는 규칙은 root의 `CLAUDE.md`와 `AGENTS.md`에 있습니다.

> 자료집을 다른 repository/환경에서 쓴다면, 이 문서의 내용을 그 환경의 `CLAUDE.md`(Claude Code) 또는
  `AGENTS.md`(Codex)에 반영해 사용하십시오.

## 근거 출처와 쓰기 범위

- `docs/`는 **읽기 전용** 정본 자료집입니다. 어떤 경우에도 `docs/` 아래에서는 아무것도
  생성/수정/삭제하지 않습니다.
- 모든 산출물은 `extended/outputs/` 아래에만 작성합니다.
- 근거 출처는 `docs/`의 ISMS-P 228개 항목(`.md` 456개, 언어별 228개이며 한국어가 정본),
  `extended/manifest.json`, `extended/index/*`, 그리고 `references/`의 원문뿐입니다. `references/`는
  local 전용 원문으로 gitignore 대상이라, 유지보수자가 직접 넣어 두지 않았다면 clone에는 없습니다.
  없다고 오류로 보지 마십시오. 모델의 일반 지식으로 인증기준/법규/수치를 단정하지 않습니다.

## 작업 순서(manifest 우선)

1. `extended/manifest.json`을 먼저 읽어 질문/작업에 관련된 항목(`no`, `path`)으로 범위를 좁힙니다.
   `docs/` 전체를 무작정 grep하지 않습니다.
2. 좁힌 항목의 `.md`만 context로 읽습니다. 각 파일은 6개 섹션(인증기준 / 주요 확인사항 / 세부 설명
   / 관련 법규 / 증적자료 / 결함사례)으로 구성됩니다.
3. 셀프 진단/mapping이 필요하면 `extended/index/defect-rulebook.json`(결함 규칙),
   `evidence-dictionary.json`(증적 사전)을 사용합니다. 두 파일은 별표 7(한국어)만 담고, 세트 구분 없이
   항목번호만 키로 씁니다. 이 번호는 세트가 다르면 서로 비교할 수 없으므로 별표 7의2나 7의3 작업에서는
   각 항목의 `.md`에서 규칙을 가져옵니다.

## 산출 규칙

- **인용 강제**: 모든 주장/판정 끝에 `[근거: <docs 경로> > <섹션명>]`을 붙입니다. 인용할 수 없는
  내용은 출력하지 않거나 "근거 없음(자료집 미수록)"으로 표기합니다.
- **placeholder**: 자료집에 없는 수치/사실은 `[확인필요]`로 비웁니다.
- **상태 표기**: 산출물 맨 앞에 `상태: AI 생성 초안 / 검토 전`, 생성 일시, 모델 버전, 근거 항목
  목록을 적습니다.
- **사람 gate**: 법규 해석, 인증 적부 판단, 정책 확정, 충족/미충족 최종 판정, 보완조치 완료 판정은
  사람이 확정합니다. 해당 산출물은 `extended/outputs/review-queue/`에 검수 항목으로도 남깁니다.
- **최신성 경계**: 자료집 기준일(세부점검항목 2023.10.31(별표 7) / 2024.7.24(별표 7의2, 7의3) /
  인증기준 안내서 2023.11.23)을 표기합니다. 2026 개편 등 미수록 개정은 단정하지 않고 "자료집 미수록,
  외부 확인 필요"로 표시합니다.
- **DLP**: 실제 개인정보/원본 증적 본문을 외부 모델에 입력하지 않습니다. 증적은 파일명/유형/metadata 수준으로만 다룹니다.

## 스타일

- 사용자 대상 문장은 존댓말을 사용합니다.
- em-dash(U+2014)와 가운뎃점(U+00B7, U+2219, U+318D)을 쓰지 않습니다. 구분/연결은 슬래시(/),
  콜론(:), 쉼표(,), 괄호, '및'으로 합니다. 원문에 가운뎃점이 있어도 산출물에서는 슬래시로 바꿉니다.

## 검증(권장 CI lint)

- `git diff -- docs/`가 비어 있어야 합니다(자료집 불변).
- `extended/outputs/` 산출물에 `[근거: docs/...]` 인용이 1개 이상 있어야 합니다.
- 산출물에 em-dash(U+2014)와 가운뎃점(U+00B7, U+2219, U+318D)이 없어야 합니다.

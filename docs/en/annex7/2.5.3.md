# 2.5.3 User Authentication

| Field | Value |
|---|---|
| Domain | 2. Protection Measure Requirements |
| Section | 2.5 Authentication and Authorization Management |
| Item | 2.5.3 User Authentication |
| Applicable certification | ISMS `●` / ISMS-P `●` |
| Korean source | 2.5.3 사용자 인증 |

## Certification criterion

User access to information systems, personal information, and important information shall apply secure authentication procedures and, where necessary, reinforced authentication methods. In addition, controls against unauthorized access, such as limits on the number of login attempts and warnings for illegal login attempts, shall be established and implemented.

## Key checkpoints

1. Is access to information systems and personal information processing systems controlled through secure user authentication procedures, such as user authentication, limits on the number of login attempts, and warnings for illegal login attempts?
2. When attempting to connect to a personal information processing system from outside via an information and communications network, are secure authentication means or secure connection means applied in accordance with legal requirements?

## Detailed explanation

When accessing information systems and personal information processing systems, access shall be controlled through secure user authentication procedures, such as user authentication, limits on the number of login attempts, and warnings for illegal login attempts.

- Examples of user authentication means

  | Field | Authentication means | Remarks |
  | --- | --- | --- |
  | Knowledge based | Password | Apply secure password composition rules and consider change cycles<br>Response needed against password theft, brute force attacks, etc.<br>Upon system installation, the default accounts and passwords provided by products, etc. must be disabled or changed |
  | Possession based | Certificate (PKI) | Secure storage of the private key needed (storage on a secure security medium recommended) |
  | Possession based | OTP (One Time Password) | Various methods exist, such as OTP tokens and mobile OTP |
  | Possession based | Other | Smart card method<br>Physical security token method, etc. |
  | Biometric based | Fingerprint, iris, face, etc. | Secure management of biometric recognition information needed<br>※ Reference: FIDO (Fast Identity Online) |
  | Other methods (can be applied as compensating controls for user authentication) | IP address | Method that restricts access with the relevant ID only from specific IP addresses |
  | Other methods (can be applied as compensating controls for user authentication) | MAC address | Method that, based on the terminal's MAC address, restricts access only from registered terminals |
  | Other methods (can be applied as compensating controls for user authentication) | Device serial number | Method that restricts access only from a specific PC or specific device (smartphone, etc.) |
  | Other methods (can be applied as compensating controls for user authentication) | Other | Method that restricts access based on location information, etc. |

- Examples of controls against account theft and illegal authentication attempts

  | Field | Description |
  | --- | --- |
  | Limit on number of authentication failures | Restrict access when authentication fails more than a certain number of times<br>※ Standards for Measures to Ensure the Safety of Personal Information, Article 5(6) |
  | Limit on connection duration | Automatically block the connection when no work is processed for more than a certain period after connecting (Session Timeout or Idle Timeout, etc.)<br>※ Standards for Measures to Ensure the Safety of Personal Information, Article 6(4) |
  | Limit on concurrent connections | Connection blocking measures or notification functions when the same account connects concurrently, etc. |
  | Warning for illegal login attempts | Blocking and notification upon connection from unregistered IP addresses such as overseas IP addresses<br>Text notification upon connection during weekends or nighttime<br>Notification upon login with special privileges such as administrators, etc. |

- When using Single Sign-On to provide work convenience, there is a possibility that damage may spread in the event of account theft, so additional protection measures such as applying reinforced authentication based on risk assessment and requiring re-authentication when accessing important systems shall be prepared.

When attempting to connect to a personal information processing system from outside via an information and communications network such as the internet, secure authentication means shall be applied in accordance with legal requirements. However, for a personal information processing system that processes the personal information of data subjects who are not users, secure connection means such as a virtual private network, or secure authentication means, may be applied.

- Applying secure authentication means refers to applying an additional authentication means beyond the procedure of identifying/authenticating whether one is a legitimate personal information handler by entering a user account and password into the personal information processing system.
- Examples of secure authentication means: certificate, security token, one time password (OTP), etc.
- When a personal information handler connects to a personal information processing system from outside via an information and communications network, compliance with the legal requirements regarding the application of authentication means is necessary.

  | Target personal information processing system | Personal information processing system that processes the personal information of data subjects who are not users | Personal information processing system that processes the personal information of users |
  | --- | --- | --- |
  | Matters requiring application | Apply secure connection means or secure authentication means<br>※ Secure connection means: virtual private network (VPN), etc. | Apply secure authentication means |

  [Reference] Application of secure authentication means upon external connection (Standards for Measures to Ensure the Safety of Personal Information, Article 6(2))

  ② When a personal information handler attempts to connect to a personal information processing system from outside via an information and communications network, the personal information controller shall apply secure authentication means such as a certificate, security token, or one time password. However, for a personal information processing system that processes the personal information of data subjects who are not users, secure connection means such as a virtual private network, or secure authentication means, may be applied.

## Related laws

- Personal Information Protection Act, Article 29 (Duty of Safety Measures)
- Standards for Measures to Ensure the Safety of Personal Information, Article 5 (Management of Access Rights), Article 6 (Access Control)

## Evidence (examples)

- Login screen of the information system and personal information processing system
- Setting screen for the limit on the number of login attempts
- Login failure message screen
- Procedures for external connection (external connection application form, status of external connectors, etc.)

## Nonconformity examples

- A case where, when a personal information handler accesses a personal information processing system that processes the personal information of users via a public external internet network, secure authentication means are not applied and authentication is performed only by the ID/password method
- A case where, upon login failure to the information system and personal information processing system, it displays in detail that the relevant ID does not exist or that the password is incorrect, and there is no limit on the number of login failures

# 2.8.4 Test Data Security

| Field | Value |
|---|---|
| Domain | 2. Protection Measure Requirements |
| Section | 2.8 Information System Introduction and Development Security |
| Item | 2.8.4 Test Data Security |
| Applicable certification | ISMS `●` / ISMS-P `●` |

## Certification criterion

To prevent leakage of operational data during the system testing process, procedures for the generation, use and management, disposal, and technical protection measures of test data shall be established and implemented.

## Key checkpoints

1. Is the use of actual operational data restricted during the development and testing process of the information system?
2. When operational data is unavoidably used in the test environment, are control procedures such as approval by the responsible person, monitoring of access and leakage, and deletion of data after testing established and implemented?

## Detailed explanation

The use of actual operational data shall be restricted during the development and testing process of the information system.

- To prevent personal information and important information from being leaked during the system testing process, test data is used by generating arbitrary data or by processing/transforming operational data before use
- Establish and implement standards/procedures for the transformation and use of test data

When operational data is unavoidably used in the test environment, control procedures such as approval by the responsible person, monitoring of access and leakage, and deletion of data after testing shall be established and implemented.

- Prepare an approval procedure for the use of operational data : define reporting and approval systems according to data importance, etc.
- Prepare and implement a data disposal procedure after the test deadline expires
- Apply access control measures in the test environment for the use of operational data
- Perform monitoring and periodic review of the replication/use of operational data, etc.

## Related laws

_No individual legal provision directly corresponding to this item is specified._

## Evidence (examples)

- Status of test data
- Test data generation rules
- When operational data is used in the test environment, the related approval history

## Nonconformity examples

- When specific standards and procedures for generating test data to be used on the development server have not been established
- When actual operational data is used as test data without processing, and without a valid reason or approval by the responsible person
- When, having obtained prior approval to use actual operational data for testing purposes for an unavoidable reason, the same level of access control as the operational database is not applied to the test database
- When actual operational data used for testing purposes is not deleted from the test database even after the test has been completed

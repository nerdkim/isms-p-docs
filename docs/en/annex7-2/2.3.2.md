# 2.3.2 Information System Protection  _( Annex 7-2 )_

| Field | Value |
|---|---|
| Domain | 2. Protection Countermeasure Requirements |
| Section | 2.3 Physical Security |
| Item | 2.3.2 Information System Protection |
| Criterion type | Annex 7-2 (special certification, relaxed certification criteria) |
| Corresponding (Annex 7) | [2.4.3 Information System Protection](../annex7/2.4.3.md) |
| Korean source | 2.3.2 정보시스템 보호 |

## Certification criterion

Information systems shall be arranged with consideration of their importance and characteristics so as to reduce environmental threats, hazards, and the possibility of unauthorized access, and communication and power cables shall be protected from damage.

## Key checkpoints

1. Are the placement locations separated with consideration of the importance, use, and characteristics of the information systems?
2. Is a method in place to easily verify the actual physical location of the information systems?
3. Are the power and communication cables safely protected from external physical damage and electrical influence?

## Detailed explanation

> ※ This item is a **relaxed certification criterion (Annex 7-2)** under the special provisions for information security management system certification. The certification criterion / key checkpoints above are the official text as relaxed/adjusted, while the detailed explanation / related laws / evidence / nonconformity examples below are the content of the "ISMS-P Certification Criteria Guide" for Annex 7 [2.4.3 Information System Protection], which is the same control area (under the relaxed criterion, it applies within the scope of the certification criterion / checkpoints above).

Placement locations shall be separated with consideration of the importance, use, and characteristics of the information systems.

- Protect systems from the outside using server racks according to the characteristics of the information systems, such as information systems, personal information processing systems, network equipment, security systems, and backup equipment
- For high-importance cases such as personal information processing systems, install locking devices on server racks so that only a minimum number of personnel can access them, and manage them in cages or similar facilities with separate physical safeguards

A method (layout diagram, asset list, etc.) shall be prepared to easily verify the actual physical location of the information systems.

- Manage physical layout diagrams (facility cross-sections, layout diagrams, etc.) and asset lists for prompt action in the event of a security incident or failure
- Include the physical location item in the asset list, etc., and keep it up to date to maintain the latest version

Power and communication cables shall be safely protected from physical damage and electrical influence.

- Take measures such as physical separation/wiring, identification labeling, maintaining distance to prevent mutual interference, and burying cables
- Apply access control to switchboards, high-voltage rooms, low-voltage rooms, etc., so that only a minimum number of authorized personnel can access them

## Related laws

_No individual legal provision directly corresponding to this item is specified._

## Evidence (examples)

- Information processing facility drawings
- Information system layout diagram
- Asset list

## Nonconformity examples

- When the system layout diagram is not updated to reflect the latest changes, so a failed information system cannot be quickly identified
- When many cables are left untidy and tangled on the server room floor or in racks, raising concerns about failures due to electrical interference, damage, water leakage, carelessness, etc.

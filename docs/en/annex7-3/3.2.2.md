## Certification criterion

Collected personal information must be maintained so that its accuracy/completeness/currency is ensured within the scope necessary for the processing purpose, by providing data subjects with management procedures.

## Key checkpoints

1. Are procedures and measures established/implemented to keep personal information accurate and up to date?
2. Are methods provided so that data subjects can maintain the accuracy, completeness, and currency of their own personal information?

## Detailed explanation

> * This item is a **relaxed certification criterion (Annex 7-3)** under the special provisions for information security management system certification. The certification criterion/key checkpoints above are the officially relaxed/adjusted text, while the detailed explanation/related laws/evidence/nonconformity examples below are drawn from the "ISMS-P Certification Criteria Guide" content for the same control area, Annex 7 [3.2.2 Ensuring Quality of Personal Information] (under the relaxed criterion, they apply within the scope of the certification criterion/checkpoints above).

Procedures and measures to keep personal information accurate and up to date must be established/implemented.

- Apply safety measures to prevent forgery/alteration/damage of personal information
- Establish/implement backup/recovery and similar systems so that the accuracy/completeness of personal information can be secured even when unlawful changes to or damage of personal information occur due to external hacking, misuse/abuse of privileges by insiders, disasters/calamities, etc.
- Apply administrative/technical measures so that input errors do not occur when a personal information handler changes personal information
- When a data subject has changed their name or resident registration number due to a name change (改名), leakage of the resident registration number, etc., establish/implement procedures to reflect this and update the data subject's personal information to the latest state

Methods must be provided so that data subjects can maintain the accuracy, completeness, and currency of their own personal information.

- Provide notice so that personal information can be modified periodically through the website
- Provide various methods (online, offline, etc.) so that data subjects can easily view and change the status of their registered personal information
- Establish and implement secure identity verification procedures for changes to personal information
- Post the changes to the personal information processing policy and its history in a way that is easy to recognize, so that data subjects can easily know the status of the personal information being collected and processed

## Related laws

- Personal Information Protection Act Article 3 (Principles for Protecting Personal Information)

## Evidence (examples)

- Data subject personal information modification/change forms (online, offline)
- Procedures for maintaining currency of personal information

## Nonconformity examples

- The case where an identity verification procedure is applied when changing member information through the internet website, but the identity verification procedure is insufficient when changing member information through a phone call with a call center agent, making unlawful changes to member information possible
- The case where a method to change personal information is provided for online members, but no method to change personal information is provided for offline members

# 2.10.2 Security of Work Devices  _( Annex 7-3 )_

## Certification criterion

When devices such as PCs and mobile devices are connected to the network for work purposes, access control measures such as device authentication and approval, access scope, and device security settings must be established and periodically inspected.

## Key checkpoints

1. Are security control policies such as device authentication, approval, access scope setting, and device security settings established/implemented for devices used for work, such as PCs, laptops, virtual PCs, and tablets?
2. To prevent personal information and important information from being leaked through work devices, are policies such as prohibition of file-sharing programs, restriction of sharing settings, and control of wireless network use established/implemented?
3. Are security measures applied to prevent the leakage/exposure of personal information and important information due to loss or theft of work mobile devices?
4. Is the adequacy of access control measures for work devices periodically inspected?

## Detailed explanation

> Note: This item is a **relaxed certification criterion (Annex 7-3)** under the special case for information security management system certification. The certification criterion/key checkpoints above are the officially relaxed/adjusted text, while the detailed explanation/related laws/evidence/nonconformity examples below are the content of the "ISMS-P Certification Criteria Guide" for Annex 7 [2.10.6 Security of work devices], which is the same control area (under the relaxed criterion, they apply within the scope of the certification criterion/checkpoints above).

For devices used for work, such as PCs, laptops, virtual PCs, and tablets, security control policies such as device authentication, approval, access scope setting, and device security settings must be established/implemented.

- Criteria for permitting work devices
- Scope of work use through work devices
- Approval procedures and methods for using work devices
- Authentication measures when connecting to the work network: device authentication, MAC authentication, etc.
- Security setting policies according to the use of work devices, such as installation of antivirus software and security programs
- Security setting policies according to the use of work devices, and measures for monitoring misuse/abuse, etc.

Note: Security management and monitoring measures according to the use of work devices (examples)
- User security setting policies for work devices (antivirus installation, security patching, caution when using in public places, data wiping in case of loss, etc.)
- Policies, education, assignment of responsibility, and disciplinary standards to prevent leakage of personal information and internal data
- Monitoring measures that can identify misuse/abuse of work devices
- Measures to inspect the safety of software installed on work devices
- Measures to prevent malicious code on work devices
- Access control measures for work devices to prevent leakage/exposure of personal information through the internet, open wireless networks, etc.

To prevent personal information and important information from being leaked through work devices, policies such as prohibition of file-sharing programs, restriction of sharing settings, and control of wireless network use must be established/implemented.

- When sharing settings are unavoidable, set an access-permission password on the work device, and remove the sharing setting after use is complete
- When file transfer is the main purpose, grant only read permission, and set write permission individually only when the other party needs to write
- Prevent intentional/careless leakage/exposure of personal information and important information through P2P programs, commercial webmail, web hard drives, messengers, SNS services, etc.
- Use of wireless networks to which security protocols such as WPA2 (Wi-Fi Protected Access 2) are applied, etc.

To prevent the leakage/exposure of personal information and important information due to loss or theft of work mobile devices, security measures such as password setting must be applied.

Note: Measures for loss/theft of work mobile devices (examples)
- Set screen lock using a password, pattern, PIN, fingerprint, iris, etc.
- Encrypt applications, data, etc. using device encryption functions, etc.
- Remote lock and remote data deletion using functions provided by mobile device manufacturers or mobile carriers (kill switch service, etc.)
- For mobile devices that process important personal information, install a mobile device management program such as MDM (Mobile Device Management) to perform remote lock, remote data deletion, access control, etc.

The adequacy of access control measures for work devices must be periodically inspected.

- Application/approval, registration/deregistration, and device authentication history of work devices
- Status of security settings of work devices, etc.

## Related laws

- Personal Information Protection Act Article 29 (Duty of safety measures)
- Standards for Measures to Secure Safety of Personal Information Article 6 (Access control)

## Evidence (examples)

- Guidelines and procedures for security control of work devices
- Registration status of work devices
- Security settings of work devices
- Device authentication and approval history of work devices
- Security inspection status of work devices

## Nonconformity examples

- The case where mobile devices such as laptops and tablet PCs are used for work purposes, but policies on permission criteria, scope of use, approval procedures, authentication methods, etc. for work mobile devices are not established
- The case where the mobile device security management guidelines in principle prohibit the use of mobile devices for work and stipulate that, when necessary, only mobile devices permitted through an approval procedure may be used for a limited period, but permitted mobile devices are not identified/managed and internal information systems can be accessed even from unapproved mobile devices
- The case where protection measures against theft/loss, such as password setting, are not applied to mobile devices used for personal information processing tasks
- The case where internal regulations prohibit the use of shared folders on work devices, but periodic inspections are not conducted, so shared folders are excessively set up and used on many work devices

## Certification criterion

User access to information systems and to personal information and important information shall apply secure authentication procedures and, where necessary, strengthened authentication methods. In addition, measures to control access by unauthorized persons, such as limiting the number of login attempts and warning of illegal login attempts, shall be established and implemented.

## Key checkpoints

1. Is access to information systems and personal information processing systems controlled through secure user authentication procedures such as user authentication, limits on the number of login attempts, and warnings of illegal login attempts?
2. When attempting to connect to a personal information processing system from outside via an information and communications network, are secure authentication means or secure connection means applied in accordance with legal requirements?

## Detailed explanation

> * This item is a **relaxed certification criterion (Annex 7-3)** established under the special case of information security management system certification. The certification criterion and key checkpoints above are the relaxed/adjusted official original text, while the detailed explanation / related laws / evidence / nonconformity examples below are the content of the "ISMS-P Certification Criteria Guide" for Annex 7 [2.5.3 User Authentication], which is the same control area (under the relaxed criterion, they apply within the scope of the certification criterion and checkpoints above).

Access to information systems and personal information processing systems shall be controlled in accordance with secure user authentication procedures such as user authentication, limits on the number of login attempts, and warnings of illegal login attempts.

- Examples of user authentication means

  | Field | Authentication means | Remarks |
  | --- | --- | --- |
  | Knowledge-based | Password | Apply secure password composition rules and consider change cycle<br>Response needed against password theft, brute-force attacks, etc.<br>Default accounts and passwords provided by products at system installation must be suspended or changed |
  | Possession-based | Certificate (PKI) | Secure storage of the private key needed (storage in a secure security medium recommended) |
  | Possession-based | OTP (One Time Password) | Various methods exist such as OTP tokens and mobile OTP |
  | Possession-based | Other | Smart card method<br>Physical security token method, etc. |
  | Biometric-based | Fingerprint, iris, face, etc. | Secure management of biometric identification information needed<br>* Reference: FIDO (Fast Identity Online) |
  | Other methods (applicable as compensating controls for user authentication) | IP address | Method that restricts access with the relevant ID to only specific IP addresses |
  | Other methods (applicable as compensating controls for user authentication) | MAC address | Method that restricts access to only registered terminals based on the terminal's MAC address |
  | Other methods (applicable as compensating controls for user authentication) | Device serial number | Method that restricts access to only a specific PC or specific device (smartphone, etc.) |
  | Other methods (applicable as compensating controls for user authentication) | Other | Methods that restrict access based on location information, etc. |

- Examples of control measures against account theft and illegal authentication attempts

  | Field | Description |
  | --- | --- |
  | Limiting the number of authentication failures | Restrict access when authentication fails more than a certain number of times<br>* Standards for Measures to Ensure the Safety of Personal Information, Article 5 (6) |
  | Limiting connection retention time | Automatically block the connection when no work is processed for a certain period after connecting (Session Timeout or Idle Timeout, etc.)<br>* Standards for Measures to Ensure the Safety of Personal Information, Article 6 (4) |
  | Limiting concurrent connections | Measures to block the connection or notification functions, etc., when the same account connects concurrently |
  | Warning of illegal login attempts | Block and notify upon connection from unregistered IP addresses such as overseas IP addresses<br>Text message notification for weekend or nighttime connections<br>Notification upon login by administrators or others with special privileges, etc. |

- When Single Sign-On (SSO) is used to provide work convenience, because there is a possibility of expanded damage in the event of account theft, additional protective measures shall be prepared based on risk assessment, such as applying strengthened authentication and requiring re-authentication when connecting to important systems

When attempting to connect to a personal information processing system from outside via an information and communications network such as the internet, secure authentication means shall be applied in accordance with legal requirements. However, in the case of a personal information processing system that processes the personal information of data subjects who are not users, secure connection means such as a virtual private network, or secure authentication means, may be applied.

- Applying secure authentication means refers to applying an additional authentication means beyond the procedure of entering a user account and password into the personal information processing system to identify/authenticate whether the person is a legitimate personal information handler
- Examples of secure authentication means: certificate, security token, one-time password (OTP), etc.
- When a personal information handler connects to a personal information processing system from outside via an information and communications network, compliance with legal requirements regarding the application of authentication means is needed

  | Target personal information processing system | Personal information processing system that processes personal information of data subjects who are not users | Personal information processing system that processes personal information of users |
  | --- | --- | --- |
  | Matters requiring application | Apply secure connection means or secure authentication means<br>* Secure connection means: virtual private network (VPN), etc. | Apply secure authentication means |

  [Reference] Applying secure authentication means for external access (Standards for Measures to Ensure the Safety of Personal Information, Article 6 (2))

  (2) When a personal information handler attempts to connect to a personal information processing system from outside via an information and communications network, the personal information controller shall apply secure authentication means such as a certificate, security token, or one-time password. However, in the case of a personal information processing system that processes the personal information of data subjects who are not users, secure connection means such as a virtual private network, or secure authentication means, may be applied.

## Related laws

- Personal Information Protection Act, Article 29 (Obligation of Safety Measures)
- Standards for Measures to Ensure the Safety of Personal Information, Article 5 (Management of Access Rights), Article 6 (Access Control)

## Evidence (examples)

- Login screens of information systems and personal information processing systems
- Setting screen for limiting the number of login attempts
- Login failure message screen
- Procedures for external access (external access application form, status of external access users, etc.)

## Nonconformity examples

- A case where, when a personal information handler accesses a personal information processing system that processes users' personal information via an open external internet network, secure authentication means are not applied and authentication is performed only by the ID/password method
- A case where, upon login failure to an information system or personal information processing system, it is displayed in detail that the relevant ID does not exist or the password is incorrect, and there is no limit on the number of login failures
